# A股技术筛选网站

一个完全使用免费数据源的 A 股技术研究网站。Python 负责下载行情、计算指标和生成 JSON，浏览器只读取 `docs/data/` 下的静态文件，因此可以直接部署到 GitHub Pages，同时适配手机卡片和电脑表格。

网站包含两个板块：

- **超跌反弹初期**：寻找明显下跌后，MACD、KDJ、均线、量能等指标刚开始改善的股票。
- **隔夜高开候选**：结合最近 60 个交易日的次日开盘统计与尾盘 30 分钟量价表现，生成观察样本，不提供买入建议。

> 网站仅用于技术研究，不构成投资建议。免费数据可能延迟，接口也可能暂时不可用。

## 环境要求

- Python 3.11
- 可访问新浪财经、AKShare、BaoStock 对应的公开数据服务
- 如需部署：一个 GitHub 仓库和已启用的 GitHub Actions

## 安装

在项目根目录执行：

```bash
pip install -r requirements.txt
```

建议使用虚拟环境：

```bash
python -m venv .venv
```

Windows 激活：

```powershell
.venv\Scripts\Activate.ps1
```

macOS / Linux 激活：

```bash
source .venv/bin/activate
```

## 常用命令

```bash
# 收盘后：更新日线、超跌候选和历史高开统计
python main.py daily

# 交易日下午：只读取已有日线缓存，更新隔夜高开候选
python main.py intraday

# 检查静态站点和 JSON 文件，缺失时创建安全的空结果
python main.py site

# 依次执行 daily、intraday、site
python main.py all

# 运行离线测试
pytest
```

本地预览网站：

```bash
python main.py serve
```

然后打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。也可以指定地址和端口：

```bash
python main.py serve --host 0.0.0.0 --port 8080
```

不要直接双击 HTML 文件预览，因为浏览器通常会阻止页面通过 `file://` 读取本地 JSON；请使用上面的本地预览命令。

## 数据源与更新机制

- **新浪财经（经 AKShare）**：A 股快照、前复权日线和盘中分钟线的首选来源。
- **腾讯财经、东方财富（经 AKShare）**：新浪接口失败时自动使用的免费行情备用来源。
- **BaoStock**：上述单只股票日线均失败时的免费备用来源。
- **不使用**：付费行情 API、数据库、OpenAI/Claude/DeepSeek 等任何大模型 API。

新浪财经网页提供免费行情，沪深京等行情通常标注为实时，但公开网页接口不承诺服务等级。AKShare 文档提示新浪日线大量连续请求可能触发 IP 限制，因此程序对新浪日线请求进行了限速，并保留多源自动回退。

日线保存在 `data/cache/daily/`。已有缓存时，每天只补最近缺失区间并保留 5 天重叠用于纠正数据；首次运行需要获取较多股票的历史行情，耗时会明显更长。GitHub Actions 使用缓存保存这些日线，后续更新通常会快很多。

盘中任务不会重新下载全部历史数据。它先读取日线缓存和全市场快照，按历史开盘表现缩小范围，再为优先级靠前的股票获取 5 分钟线，计算最后 30 分钟走势。

如果某次任务在生成完整有效结果之前失败，程序会直接退出，不覆盖 `docs/data/` 中上一版有效 JSON。写入采用同目录临时文件再替换，避免产生半截文件。

## 筛选范围

默认基础条件位于 `config/config.yaml`：

- 仅筛选沪市主板（600/601/603/605）和深市主板（000/001/002/003）
- 最新价 10 元至 20 元（包含边界）
- 排除 ST、*ST、停牌
- 排除上市不足 120 个交易日
- 排除近 20 日平均成交额低于 5000 万元
- 按主板、创业/科创、北交所不同涨停幅度排除当天接近涨停的股票
- 排除近 3 日累计涨幅超过 12% 的股票

### 修改价格范围

编辑：

```yaml
screening:
  price_min: 10.0
  price_max: 20.0
```

### 修改评分阈值

编辑：

```yaml
oversold:
  score_threshold: 65

overnight:
  score_threshold: 50
```

所有阈值集中在 `config/config.yaml`，包括流动性、上市天数、成交量倍数、尾盘跳水和历史低开风险等。

## 超跌反弹策略

程序计算 MA5/10/20/60、MACD、KDJ、RSI6、布林带、5 日均量、10/20 日涨跌幅。

股票需至少满足两项超跌条件：20 日最大回撤、10 日跌幅、KDJ 低位、J 值低于 0、RSI6 低位、跌破布林下轨。随后根据以下维度评分：

| 维度 | 满分 |
|---|---:|
| MACD | 20 |
| KDJ | 20 |
| 均线 | 15 |
| 成交量 | 15 |
| 超跌程度 | 10 |
| RSI | 10 |
| K线质量 | 5 |
| 流动性 | 5 |

系统重点识别 MACD 负柱连续缩短、DIF 向上、低位金叉、KDJ 低位金叉、J 值回升、重回 MA5、MA5 走平向上和温和放量。长上影或仍处于 MA20 下方会产生风险提示和扣分。

## 隔夜高开策略

历史统计严格使用：

```text
次日开盘收益率 = 次日开盘价 ÷ 当日收盘价 - 1
```

每只股票统计最近 60 个有效样本的高开率、平均/中位数收益、高开超过 0.5%/1% 的概率、低开超过 1% 的概率和最大低开幅度。样本不足 40 个或历史低开风险超过阈值会直接排除。

隔夜板块不再按当日涨跌幅、近 3 日累计涨跌幅、最后 30 分钟跌幅或日内区间位置做硬性排除，接近涨停或跌停的股票也可以参与评分。尾盘走势、区间位置、均价、量能和上影线仍会影响评分或形成风险提示。评分满分 100：

| 维度 | 满分 |
|---|---:|
| 历史次日高开率 | 20 |
| 历史平均开盘收益 | 15 |
| 近期高开稳定性 | 10 |
| 低开风险 | 10 |
| 样本稳定性 | 5 |
| 尾盘30分钟走势 | 10 |
| 尾盘量价配合 | 10 |
| 收盘位置 | 8 |
| 是否站上当日均价 | 5 |
| 日K质量 | 4 |
| 流动性 | 3 |

## JSON 输出

网站读取：

```text
docs/data/oversold_latest.json
docs/data/overnight_latest.json
docs/data/metadata.json
docs/data/history/
```

`metadata.json` 包含最新交易日、最后更新时间、任务状态、扫描数量、候选数量，以及两个策略各自的最近状态。每次成功结果也会保存到 `docs/data/history/`，默认每个策略保留最近 60 份。

个股最近 120 日日 K、均线、成交量、MACD、KDJ、RSI 和布林带数据直接放在候选的 `detail.chart` 中，静态页面无需后端即可打开详情图表。

## GitHub Pages 部署

1. 创建 GitHub 仓库并把本项目推送到默认分支（通常是 `main`）。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/docs`，保存。
5. 等待 Pages 完成发布。网址通常为 `https://你的用户名.github.io/仓库名/`。

前端所有路径均为相对路径，因此可以部署在 GitHub Pages 的仓库子路径下。

## GitHub Actions 启用

仓库包含两个工作流：

- `.github/workflows/daily-update.yml`：工作日 UTC 10:30，即北京时间 18:30。
- `.github/workflows/intraday-update.yml`：工作日 UTC 05:30、06:00、06:30、06:45，即北京时间 13:30、14:00、14:30、14:45。

启用步骤：

1. 打开仓库 **Actions**，允许工作流运行。
2. 打开 **Settings → Actions → General → Workflow permissions**。
3. 选择 **Read and write permissions**，保存。
4. 先在 **Actions → 每日收盘更新 → Run workflow** 手动运行一次，建立日线缓存。
5. 每日任务成功后，再手动测试一次盘中任务。

定时任务由 GitHub 调度，繁忙时可能晚几分钟开始。首次每日任务需要下载历史数据，预留时间比后续增量更新更长。

## 项目结构

```text
.
├─ .github/workflows/       # 定时更新
├─ config/config.yaml       # 全部可调参数
├─ data/cache/              # 日线缓存（不提交）
├─ data/output/             # 本地中间结果
├─ docs/                    # GitHub Pages 静态网站
├─ scripts/                 # 更新与站点生成脚本
├─ src/                     # 数据源、指标、策略、评分、存储
├─ tests/                   # 离线测试
├─ main.py                  # 统一命令入口
└─ requirements.txt
```

## 已知限制

- 免费行情接口没有可用性承诺，可能延迟、限流或临时变更字段。
- GitHub Actions 的定时触发时间可能有排队延迟，不适合秒级实时交易。
- 新浪盘中行情可以持续变化，但静态网站只会在 GitHub Actions 生成新 JSON 后更新；当前仍按 13:30、14:00、14:30、14:45 四个时点运行。
- 盘中分钟线只对历史统计优先级较高的有限候选获取，数量由 `data.intraday_shortlist` 控制。
- 复权方式、行情修订和不同数据源的成交量单位可能存在差异；程序已做标准化和安全除法，但仍建议抽样核对。
- 所有评分只是透明、可重复的技术规则，不是收益保证，也不是投资建议。
